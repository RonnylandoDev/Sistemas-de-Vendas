🛠️ Tecnologias e Linguagens Utilizadas
Interface & Deploy Web: Streamlit — construção de formulários interativos, tabelas dinâmicas e painéis na barra lateral (sidebar).   
Manipulação e Análise de Dados: Pandas — leitura, agregação matemática e manipulação tabular de DataFrames.   
Visualização de Dados: Plotly Express — criação de gráficos interativos de barras e setores (pizza).   
Armazenamento de Dados: CSV (vendas.csv) para persistência de registros.
